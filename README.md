# Distributor Order Management System

About the Project
The Distributor Order Management System is a web-based application designed to simplify product inventory, retailer management, order processing, and payment tracking. It helps distributors manage their daily business operations through a centralized platform.

Features
Authentication: Secure login and role-based access for Distributor and Retailer.
Product Management: Manage products, prices, and inventory stock.
Retailer Management: Manage registered retailers and distributor-associated retail partners.
Order Management: Place, track, and process orders.
Payment Management: Track order payments and payment status.
Dashboard: View important business information and summaries.
Reports: Access order, inventory, and payment-related reports.

Technologies Used

Backend
- Java
- Spring Boot
- Spring Web (REST APIs)
- Spring Data JPA / Hibernate
- Spring Security
- JWT Authentication

Frontend
- HTML
- CSS
- JavaScript

Database
- PostgreSQL

Tools
- IntelliJ IDEA
- Maven
- Git and GitHub

User Roles
- Distributor: Manage products, inventory, retailers, orders, payments, and reports.
- Retailer: Browse products, place orders, and manage payments.

Project Purpose
This project demonstrates the application of Java, Spring Boot, REST APIs, database integration, and role-based authentication in a distributor business management system.
